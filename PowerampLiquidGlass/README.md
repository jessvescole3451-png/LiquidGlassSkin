# Liquid Glass — Poweramp Skin

Un skin para Poweramp con efecto de vidrio translúcido (glassmorphism).

## Cómo obtener el APK (sin instalar nada)

### Paso 1: Subir a GitHub
1. Crea una cuenta gratis en **https://github.com**
2. Haz clic en **"New repository"** → llámalo `LiquidGlassSkin`
3. Marca **"Add a README file"** y crea el repo
4. En el repo, haz clic en **"uploading an existing file"**
5. Sube **todos los archivos** de esta carpeta `PowerampLiquidGlass`
6. Haz clic en **"Commit changes"**

### Paso 2: El APK se compila solo
- Después de subir los archivos, ve a la pestaña **"Actions"** del repo
- Verás el proceso de compilación corriendo automáticamente
- En 2-3 minutos aparecerá un ✅ verde

### Paso 3: Descargar el APK
1. Haz clic en el workflow completado ✅
2. Al final de la página verás **"Artifacts"**
3. Descarga **"LiquidGlass-Poweramp-Skin"**
4. Extrae el ZIP → encontrarás el **APK**

### Paso 4: Instalar en tu Android
1. Copia el APK a tu teléfono
2. Activa **"Instalar apps de fuentes desconocidas"** en Ajustes
3. Toca el APK para instalarlo
4. Abre la app → toca **"Apply Skin"**
5. ¡Disfruta tu skin Liquid Glass! 💎
